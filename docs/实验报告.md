## 组内 E5：原始复现（本人核对）

以下 E5–E7 章节是组内已有实验结果的摘要，不声称由本人重新执行。

组内步骤：`python3 scripts/lab_cloud.py e5 --out work/e5-01 --image course1020-buildchecker:241880536`。容器内实际执行 clean → `strace -ff -s 4096 -o trace/t -e trace=%file,%process make -p app > make-db.txt` → `./app`。

| 检查项 | 预期 | 实际 | 证据 |
|---|---|---|---|
| 构建与运行 | 成功 | 退出码 0 | `work/e5-01/evidence/build-stderr.log` |
| 程序输出 | `1` | `1` | `work/e5-01/evidence/program-output.txt` |
| Makefile 声明 | `main.o: main.c unused.h` | 同 | `work/e5-01/evidence/make-db.txt:1061` |
| 实际读取 | 成功打开 `config.h` | `openat(AT_FDCWD, "config.h", O_RDONLY\|O_NOCTTY) = 4` | `work/e5-01/evidence/trace/t.16:580` |

结论：**MD = `main.o → config.h`**（读了但未声明）；**RD = `main.o → unused.h`**（声明了但 7 个进程的 trace 中零次打开）。返回值 `4` 是关键判据：若为 `-1 ENOENT` 则只表示尝试过，不构成依赖。

进程归属：本次 trace 共 7 个进程（`t.14`–`t.20`，行数 72/115/582/26/135/104/156）。根进程为 `make`，其直接子进程构成一个 recipe job，job 的全部后代（`cc` → `cc1`、`as`）归属同一 job；job 的唯一最终输出即目标。

与论文原型的差异：论文用 ptrace 拦截 Make 及子进程，本实验用 `strace -ff` 事后解析；仅单次 clean build，无增量能力；样例为 4 文件教学项目而非真实基准项目。`strace` 只能观测系统调用，无法证明字节级读取，本阶段以"成功 read-open"作为读取证据，属明确的教学档位近似。

## 组内故障与限制记录

**环境故障（与算法无关）**

1. `doctor` 报 `mem_gib=3.5 低于最低要求 4`：实例为 4 GiB 规格，内核/CRI 保留后 `MemTotal` 为 3.5 GiB。不影响实验（门禁 8 项串行执行，单容器峰值数百 MB），但 `环境自检` 退出码为 1。已在 C01 备注。
2. 首次 E5 因镜像 tag 未创建返回**退出码 125**（`docker run` 自身失败，非检测失败）；`docker tag` 后重跑退出码 0。失败目录留档为 `work/e5-01-failed-tag`。此例用于区分**环境故障（125）与目标故障（1）**。
3. `github.com:443` 三次中断：TCP 连接超时、`Error in the HTTP2 framing layer`、`Empty reply from server`。分别用重试、临时 `http.version=HTTP/1.1`、以及改用 GitHub Contents API（走 `api.github.com`）绕过；`api.github.com` 全程正常，故 `gh` 侧（看运行、开 PR、合并）未受影响，代码提交与 CI 触发最终全部正常完成。
4. `raw.githubusercontent.com` 不可达（与本实验无关，CI 在 GitHub 自有 runner 上执行）。

**目标故障（设计内，用于验证门禁）**：构建失败（删 `config.h`）、多输出（单规则产出两个文件）、运行超时（`sleep 10` + `--timeout 1`）。三者均按预期返回 `CHECK_FAILED` / `UNSUPPORTED` / `TIMED_OUT`，且超时场景的容器已被清理。

**限制（教学档位，不可外推）**

- 检测器仅支持单个 Make 进程；递归 Make、单 job 多输出、符号链接、`fchdir`、数字 fd 相对路径均显式拒绝（`Unsupported`），不会静默给出错误结论。
- 以"成功 read-open"近似"被读取"，不能证明字节级读取。
- 样例为 4 文件教学项目，`elapsed_ms=126`，不代表论文在真实项目上的性能；不重跑论文全量实验，也不声明达到论文的加速比。
- 门禁的八个 case 是**小型明确的教学 oracle**，非论文基准。
