# e11e12-1 接口契约

|接口|请求/响应|状态码|
|---|---|---|
|POST /v1/jobs|idempotency_key、input(mode/repo/base/target/candidate等)；返回job_id/status|202，错误输入400，幂等冲突409|
|GET /v1/jobs/{job_id}|任务状态、trace_id、error|200，不存在404|
|GET /v1/jobs/{job_id}/artifacts|阶段清单与artifact URI/SHA256|200，结果未生成409|
|GET /v1/jobs/{job_id}/files/{相对路径}|产物文件与X-Content-SHA256|200，不存在或越界404|

任务状态 QUEUED、RUNNING、SUCCEEDED、FAILED、TIMED_OUT。输出 envelope 的 schema_version、job_id、trace_id、kind、commit、status、data、artifacts 为消费者依据。

artifact://job编号/相对路径 由该任务文件接口解析。MD消费需核对目标commit和内容哈希。基线与目标提交不同是正常的，必须记录两者。

真实项目适配时将仓库和候选准备到API服务器data/下。服务仅开放到本地，A/B通过SSH转发访问。
