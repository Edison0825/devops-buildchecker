## 4. 安全打包命令模板

> 在服务器仓库根目录执行。先列清单和检查大小，再打包。将 `<目录>`、`<包名>` 替换为确认过的字面值；不要把私钥、token、`.env` 或整个主目录打入包中。

### 4.1 记录环境

```bash
mkdir -p final-evidence/environment
git rev-parse HEAD > final-evidence/environment/git-head.txt
git log --oneline --decorate -n 30 > final-evidence/environment/git-log.txt
docker version > final-evidence/environment/docker-version.txt
docker image ls --no-trunc > final-evidence/environment/docker-images.txt
uname -a > final-evidence/environment/host.txt
```

### 4.2 先检查目录

```bash
du -sh <目录>
find <目录> -type f -print | sort > files-before-pack.txt
python3 scripts/secret_scan.py <目录>
```

若扫描命中，先判断是否为测试用假密钥；真实凭据必须移除或脱敏，并重新扫描。不要为了“零命中”删除有价值的普通失败日志。

### 4.3 打包并计算哈希

```bash
tar --sort=name --mtime='UTC 2026-01-01' \
  --owner=0 --group=0 --numeric-owner \
  -czf <包名>.tar.gz <目录>

shasum -a 256 <包名>.tar.gz > <包名>.tar.gz.sha256
shasum -a 256 -c <包名>.tar.gz.sha256
```

Linux 若没有 `shasum`，使用：

```bash
sha256sum <包名>.tar.gz > <包名>.tar.gz.sha256
sha256sum -c <包名>.tar.gz.sha256
```

### 4.4 下载后复核

```bash
shasum -a 256 -c <包名>.tar.gz.sha256
tar -tzf <包名>.tar.gz > <包名>.contents.txt
```

建议从包中随机抽取 `result.json`、补丁和日志，与服务器原文件分别重算哈希。对 `result.json` 的 `artifacts[]` 应编写或复用脚本逐项核对 `bytes` 和 `sha256`，不能只校验外层压缩包。
